# Knight's Journey
* This is a simple platform game featuring a knight traveling through a series of different settings
* The player is able to move forward, backwards, and jump
* The player is able to take different routes that will lead to the same outcome
* Some of the routes have different difficulties
* The player is able to collect coins through the different routes
* Falling off the platform will land the player into a "death zone" that will take them back to the start
* After reaching the end of the scene, the player can repeat the level
